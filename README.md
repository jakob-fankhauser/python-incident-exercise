# Order Confirmation Incident Exercise

Timebox: 15-20 minutes. Python 3.12 recommended. All data is synthetic.

## Context and contract
This API receives structured JSON from an upstream document-extraction service.
There is no LLM call or hidden keyword-based mock. The request body is the actual
input used by the application. Some supplier confirmations fail with HTTP 500.

The agreed input contract accepts delivery dates in BOTH formats:
- ISO: YYYY-MM-DD
- German: DD.MM.YYYY

Successful responses must return the date as YYYY-MM-DD. Invalid or impossible
dates must return HTTP 422 without changing the order. Unknown orders return 404.
The in-memory dictionary is intentional; persistence is out of scope.

## Your task
1. Use the logs and sample requests to reproduce and explain the incident.
2. Implement a small fix preserving the contract above.
3. Add regression tests for a German date and an invalid date.
4. Briefly explain how you would verify and safely release the fix.

Think aloud. No database, cloud setup, authentication or major refactoring needed.

## Local setup (Linux / macOS)
Run from this directory:
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -v
python -m uvicorn app:app --reload
```
If Ubuntu reports missing ensurepip, install the venv package matching your Python
version first (for Python 3.12: sudo apt install python3.12-venv).

Windows PowerShell: create with `py -m venv .venv`, activate with
`.venv\Scripts\Activate.ps1`, then use the same `python -m ...` commands.

## Browser
With the server running, open http://127.0.0.1:8000/docs.
Expand POST /confirmations, select Try it out, paste a sample JSON body and Execute.
Use the ENTIRE JSON object, not a text query parameter.

## Sample requests
See samples/iso.json, samples/supplier.json and samples/invalid.json.
Example from a second terminal while the server runs:
```bash
curl -i -X POST http://127.0.0.1:8000/confirmations -H 'Content-Type: application/json' --data @samples/supplier.json
```
